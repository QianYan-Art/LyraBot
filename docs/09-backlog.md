## 2. 推迟

- 权限隔离：模型 shell 与抖音 socket 不做隔离。运行用户本就有免密 sudo，隔离需要另设执行用户，属架构调整。
- SQLite 读写分离与维护调度：目前读写同线程串行，出现读延迟问题再加只读连接。
- 按压缩点裁剪历史读取：构建上下文时只读最近 compaction 之后的条目。
- 主动消息额度原子计数：当前发送基本串行，暂无竞争。
- systemd 看门狗：单元为 `Type=simple`，未实现 sd_notify，以 `Restart=always` 兜底。
- 通用 MCP 客户端：阿颜决定推迟，外部工具扩展口只保留在设计层面。
- OneBot（个人号）适配器：只预留能力位。
- grok 的 web_map 与 Tavily 兜底：未从 Hermes grok-search 移植。
- shell 审计日志轮转：`/var/log/qya/audit.jsonl` 增长很慢，暂未配置 logrotate。

## 3. 未采纳

- 向量检索与联想网络：需要常驻嵌入模型；记忆只有几千字，本来整份注入提示词。
- 情绪天气、“做梦”独白与主动开口：唐语歌不做主动发消息的形态，有时间的事靠当场设定时提醒。
- MCP / context-mode 压缩工具输出：重活的工具输出本来就不进唐语歌的上下文，执行者侧已有折叠与输出落盘。
- `/restart!` 命令：进程重启由部署流程执行。
- 原设计的 `send` 工具：执行者媒体随〔后台结果〕由唐语歌那一轮发出即可。
